## MetroMotif

### Overview
MetroMotif is a sleek, single-page website designed to showcase events and activities. The site includes a navigation menu, a welcoming home section, a gallery of event photos, and a registration form for visitors to sign up for events. The project highlights proficiency in HTML, CSS, and JavaScript.

### Key Features

- **Navigation Bar:**
  - A clean and responsive navigation bar that links to different sections of the page (Home, Gallery, Events).
  
- **Home Section:**
  - A welcoming section with a title and introductory text, designed to engage visitors.

- **Gallery Section:**
  - A dynamic gallery with thumbnails that expand into a lightbox modal for a larger view.
  - Each photo container includes an overlay with a description and a call to action.

- **Events Registration:**
  - A user-friendly registration form for event sign-ups, capturing essential visitor information.
  - Includes fields for first name, last name, email address, and phone number, with a submit button.

- **Footer:**
  - A simple footer with the website’s URL and copyright information.

### Technologies Used
- **HTML:** For the structure of the website.
- **CSS:** For styling and layout (external stylesheet linked).
- **JavaScript:** For interactive elements like the gallery lightbox and form handling.
